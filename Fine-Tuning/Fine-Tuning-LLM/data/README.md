# Data

`train.jsonl`, `val.jsonl`, `test.jsonl` are generated by `04_Data_preparation.ipynb` (or `python src/prepare_data.py`). They are git-ignored.

Format, one object per line:
```json
{"messages":[{"role":"user","content":"..."},{"role":"assistant","content":"..."}]}
```

## Where to download data
| Dataset | URL | Use |
|---|---|---|
| FineTome-100k (default) | https://huggingface.co/datasets/mlabonne/FineTome-100k | general instruction following |
| Bitext customer support | https://huggingface.co/datasets/bitext/Bitext-Gen-AI-Chatbot-Customer-Support-Dataset | support chatbot |
| Alpaca-cleaned | https://huggingface.co/datasets/yahma/alpaca-cleaned | simple instruction/response |
| Dolly-15k | https://huggingface.co/datasets/databricks/databricks-dolly-15k | Q&A, summarisation |
| OASST2 | https://huggingface.co/datasets/OpenAssistant/oasst2 | multi-turn chat |
| Browse more | https://huggingface.co/datasets?task_categories=task_categories:text-generation | |

They download automatically through `datasets.load_dataset(...)`; no manual download is needed.
Check each dataset's license before commercial use.
